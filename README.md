# NICU Arabic Dashboard

Neonatal Intensive Care Unit Dashboard with full Arabic interface support.

## Features

- Patient cards with color-coded status (green, blue, red)
- Medication tracking with dosage times
- Quick action buttons for feeding, output, and urination
- Lab image upload with camera support
- TPN and fluids status tracking
- LocalStorage persistence
- RTL Arabic interface

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Supabase (PostgreSQL database)

## Getting Started

```bash
npm install
npm run dev
```
